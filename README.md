# Проект E-commerce Ядро (market_engine)

Инструмент представляет собой базовую структуру (ядро) для работы интернет-магазина на основе объектно-ориентированного программирования (ООП).

## Реализованный функционал
* **Абстрактный класс `BaseProduct` и класс `Product`**: Определяют базовый интерфейс и логику товаров (название, описание, цена с проверками, остаток, сложение стоимости товаров одного типа).
* **Класс-миксин `CreationLogMixin`**: Автоматически выводит в консоль информацию о классе и параметрах при создании любого нового объекта продукта.
* **Наследники `Smartphone` и `LawnGrass`**: Специализированные категории товаров с уникальными характеристиками.
* **Абстрактный класс `BaseContainer`, `Category` и `Order`**: Группируют товары в категории, оформляют заказы, отслеживают глобальные счетчики и поддерживают итерацию (`CategoryIter`).
* **Загрузка данных**: Функция `load_data_from_json` для разбора JSON-каталога.
