# Проект E-commerce Ядро (market_engine)

Инструмент представляет собой базовую структуру (ядро) для работы интернет-магазина на основе объектно-ориентированного программирования (ООП).

## Реализованный функционал
* **Класс `Product`**: Управляет сущностями товаров (название, описание, цена, остаток).
* **Класс `Category`**: Группирует товары в категории и автоматически отслеживает глобальные счетчики количества созданных категорий и уникальных наименований товаров.
* **Загрузка данных**: Реализована функция `load_data_from_json` для автоматического разбора JSON-файлов конфигурации каталога товаров и преобразования их в объекты системы.
